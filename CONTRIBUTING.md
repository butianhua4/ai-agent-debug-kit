# Contributing

Thanks for improving AI Agent Debug Kit.

## Local Development

No install step is required.

Open `index.html` in a browser and edit:

- `index.html`
- `styles.css`
- `script.js`

Run a quick syntax check:

```bash
node --check script.js
```

## Good First Contributions

- Add a new sample log scenario.
- Improve risk flag wording.
- Add pricing presets.
- Improve exported Markdown report structure.
- Add parser support for another agent framework log shape.

## Pull Request Checklist

- The app still opens without a build step.
- `node --check script.js` passes.
- No real secrets, private logs, or customer data are committed.
- README or ROADMAP is updated if behavior changes.
