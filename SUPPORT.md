# Support

AI Agent Debug Kit is a local-first developer tool. Support is handled through public GitHub issues.

## Before Opening An Issue

- Try the public demo: https://butianhua4.github.io/ai-agent-debug-kit/
- Check `docs/CLI_REFERENCE.md` for CLI behavior.
- Check `docs/CI_USAGE.md` for CI gate examples.
- Review `docs/examples/sample-report.md` and `docs/examples/sample-report.json`.

## What To Include

For parser, export, or UI issues, include:

- browser and operating system
- input format: JSONL, JSON, pretty JSON, wrapped array, or plain text
- minimal redacted sample
- expected summary, report, or JSON output
- whether the issue appears in the browser app, CLI, or extension prototype

## Log Safety

Do not paste real secrets or private customer logs into issues.

Before sharing samples, remove:

- API keys
- access tokens
- passwords
- private repository names
- customer or user personal data

## Best Issue Templates

- Bug report: parser, UI, or export problems
- Log format support: support for a new AI agent log shape
- Feature request: new workflow or report behavior
