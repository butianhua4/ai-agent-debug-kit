# Changelog

## 0.4.0

### Added

- Zero-dependency browser app.
- JSONL, JSON, pretty JSON, wrapped arrays, and plain-text parsing.
- Run A/B comparison.
- Configurable model pricing and pricing presets.
- File import and drag-and-drop log loading.
- Local snapshot history.
- Redacted Markdown report export.
- Repeated message and retry-loop detection.
- Repeated-pattern section in Markdown reports.
- Shared parser/report core.
- Node CLI report generator.
- CLI JSON output for automation.
- CLI `--max-errors` gate for CI.
- Smoke tests and GitHub Actions checks.
- CI release artifact upload.
- Release package builder, manifest, and validation.
- Browser extension prototype.
- Extension manifest validation.
- Product preview image.
- Store listing, privacy, launch, and CI usage drafts.

### Changed

- Release packaging no longer depends on PowerShell and works cross-platform.
- README now includes a feature matrix for Web App, CLI, and Extension Prototype.
