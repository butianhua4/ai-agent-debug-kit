## Gig Description

Is your automation failing and blocking leads, operations, support, sales, content, or delivery?

I help diagnose and rescue failed AI automations and workflow systems, including:

- n8n workflow errors
- Make scenario failures
- Zapier / Salesforce / CRM mapping errors
- OpenAI or Claude API automation issues
- webhook payload and JSON field mismatches
- AI node returning empty or invalid output
- broken loops, branches, retries, or error handling
- CI automation and release workflow failures
- AI agent log and tool-call diagnosis

I work from safe, sanitized materials:

- error screenshots
- redacted logs

I do not need your password, API key, token, cookie, wallet, payment access, KYC, tax, payout access, or private customer database for the first diagnostic.

What you get:

- clear failure summary
- likely root cause
- risk and blocker list
- safe fix sequence
- validation checklist
- handoff report your team can follow

For larger systems, I can scope a 48-hour rescue sprint for multiple workflows, retry/error handling, monitoring notes, and a prevention runbook.

Please message me before ordering if your workflow needs direct platform access, private repositories, regulated data, or customer records. I will help you define the safest scope first.

## FAQ

### Can you fix it without my password?

Yes for diagnosis and many rescue plans. I start with sanitized logs, screenshots, public links, workflow structure, and redacted exports. If privileged access is required later, I will stop and describe what your own team should do safely.

### Can you guarantee the automation will be fixed?

I can guarantee a scoped diagnosis, evidence-based repair plan, and clear handoff. Final implementation depends on the system, third-party APIs, access limits, and the materials available.

### What tools do you support?

n8n, Make, Zapier, OpenAI API, Claude API, webhooks, JSON mapping, CRM/API integrations, Node.js/Python automation scripts, CI workflows, and AI agent logs.

### What should I send first?

Send the tool name, expected result, actual result, redacted error screenshot/log, and the highest-impact workflow. Do not send credentials.

### What is not included?

I do not handle payment setup, KYC, tax, wallets, payout setup, hacking, spam, platform bypassing, fake engagement, credential sharing, or requests that require private secrets in chat.
