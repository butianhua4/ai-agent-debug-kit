# Roadmap

## v1

- Parse JSONL, JSON, and plain-text logs.
- Show event, tool, error, and cost metrics.
- Export Markdown report.

## v2

- Add configurable input/output token pricing.
- Add Run A / Run B comparison mode.
- Include comparison output in exported reports.

## v3

- Add multiple demo scenarios.
- Add local snapshot history.
- Improve report risk flags and recommendation text.

## Next

- CLI version for CI logs.
- Browser extension wrapper.
- Import OpenAI Responses API traces.
- Highlight repeated tool failures and retry loops.
- Export redacted report variants.
