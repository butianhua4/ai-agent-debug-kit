第一步先做脱敏诊断，确认问题是不是字段、触发器、权限、重试循环或下游 API 规则变化。

## 知乎 / 掘金短帖

很多 AI 自动化故障不是模型问题，而是流程工程问题：

- Webhook payload 变了
- JSON 字段路径错了
- 下游 API 规则变了
- 重试造成重复写入
- Token 过期但错误提示不清楚
- AI 输出格式不稳定

我把这类问题做成了一个 299 元入门诊断：只看脱敏报错、截图、输入输出样例，交付一页故障地图和修复顺序。

目标不是一上来代你登录修，而是先把问题定位清楚，避免乱改生产流程。
