## Mobile Posting Steps

1. Upload the eight images in the listed order.
2. Paste the platform-specific title and body.
3. Add the first reply or pinned comment immediately.
4. If a buyer replies, ask for the buyer intake prompt.
5. Do not open unknown external links.
6. Do not request or accept passwords, API keys, tokens, cookies, ID documents, payment data, wallet data, or private customer data.
7. If the buyer wants login-based repair, re-scope to a report-only diagnosis first.

## Success Definition

This posting is successful if it creates one of these:

- a buyer sends a redacted error screenshot;
- a buyer asks whether their tool is supported;
- a buyer asks for 299 diagnosis scope;
- a buyer asks for 999 / 1999+ repair after seeing the diagnostic boundary.

Do not count link spam, off-platform payment requests, wallet/KYC requests, or "already paid, confirm this link" messages as real leads.
