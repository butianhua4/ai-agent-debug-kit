# Store Listing Draft

## Extension Name

AI Agent Debug Kit

## Short Description

Inspect AI agent logs, tool calls, errors, cost, and risk flags in a lightweight browser popup.

## Detailed Description

AI Agent Debug Kit helps builders inspect AI agent logs without setting up a full observability stack.

Paste JSONL, JSON, or plain-text logs into the popup and get a quick summary of:

- total events
- tool calls
- errors and warnings
- risk flags
- debugging recommendation

The full web app also supports Run A/B comparison, local snapshot history, configurable pricing, redacted Markdown export, and a CLI report generator.

The extension prototype does not request browser permissions and does not send logs to a server.

## Category

Developer Tools

## Language

English

## Privacy Summary

AI Agent Debug Kit runs locally. Logs are processed in the browser and are not uploaded to a server by this extension.

Users should avoid pasting secrets into any tool unless they are comfortable storing them in the current browser session.
