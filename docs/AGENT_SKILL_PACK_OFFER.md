# Agent + Skill Pack Offer

## Buyer Promise

I will turn one repeatable workflow into a small, documented AI agent + skill pack that a team can reuse safely.

This is for buyers who already use ChatGPT, Claude, Cursor, Codex, Make, n8n, Zapier, GitHub Actions, or internal AI tools, but their process still depends on repeated manual prompts and unclear handoffs.

## Best-Fit Use Cases

- Support triage agent for common customer questions.
- Developer assistant skill for bug report cleanup, log review, or PR checklist generation.
- Operations agent for daily report drafting, alert review, or task routing.
- Sales intake agent for qualifying leads before a human follow-up.
- Content QA skill for checking brand voice, missing fields, or risky claims.
- CI / automation guardrail skill for flagging failed runs before deployment.

## Not a Fit

- Fully autonomous account operation.
- Payment, KYC, tax, wallet, identity, or compliance submission.
- Private repository work without safe access boundaries.
- Scraping, spam outreach, platform bypass, or credential handling.
- Guaranteed revenue, guaranteed rankings, or guaranteed order volume.

## Buyer Intake

Ask the buyer to provide:

1. What workflow should the agent or skill help with?
2. Who will use it?
3. What input will the user paste or upload?
4. What output should the agent produce?
5. What should the agent refuse, escalate, or ask a human to handle?
6. What tone, format, or structure should be followed?
7. Do you have 2-3 examples of good output?
8. Do you have 1-2 examples of bad or risky output?

Do not ask for secrets, passwords, private tokens, payment data, KYC documents, or customer personal data.

## Delivery Checklist

- Confirm the workflow is narrow enough for the selected package.
- Confirm no secrets or sensitive personal data are needed.
- Write the agent role in plain operational language.
- Split repeatable actions into skill blocks.
- Add trigger rules so the user knows when to run each block.
- Add refusal and escalation rules.
- Add test examples that cover normal, edge, and unsafe cases.
- Add an operator handoff note.
- Run the pack against the buyer's redacted examples.
- Deliver as Markdown, PDF, or copy-ready text depending on buyer preference.
