# 299 Yuan AI Automation Diagnosis One-Pager

This is a buyer-facing Chinese sales and delivery sheet for a low-risk first order. It is designed for Xianyu, Xiaohongshu, WeChat groups, private communities, and Fiverr buyer clarification.

## Buyer Version

### 299 元 AI 自动化故障诊断

适合你已经有一个 AI 自动化流程，但它正在报错、卡住、输出不稳定，或者你不知道问题到底出在提示词、节点配置、JSON、Webhook、API、权限还是模型调用上。

我不需要登录你的账号，也不需要你的密码、API Key、Cookie、Token、身份证、付款信息或生产环境权限。你只需要提供脱敏后的错误截图、错误文本、流程截图或样例输入输出，我会帮你先做一次独立诊断。

### 适合这些情况

- n8n、Make、Zapier、Coze、Dify、FastGPT、AI Agent、Webhook 或自动化流程失败。
- JSON / JQ / 字段映射 / Webhook 请求体 / API 返回格式对不上。
- AI 输出不稳定，流程偶尔成功偶尔失败。
- Node.js、Python、CLI 脚本或 GitHub Actions 自动化报错。
- 你找不到失败节点，不确定应该先改哪里。

### 你需要发什么

请尽量一次性发这些内容，越完整越快判断：

1. 你用的平台或工具名称。
2. 失败发生在哪一步。
3. 完整错误文本或截图。
4. 你原本希望它输出什么。
5. 它现在实际输出了什么。
6. 最近有没有改过提示词、节点、字段、API 或环境变量。
7. 脱敏后的样例输入和样例输出。

### 不要发这些内容

为了保护你自己，也为了避免账号风险，请不要发：

- 密码、验证码、API Key、Token、Cookie。
- 身份证、银行卡、付款截图、钱包信息。
- 未脱敏的客户数据、手机号、邮箱、订单信息。
- 私有仓库、生产后台、公司内部系统登录权限。
- 任何要求绕过平台、安全验证、付款规则或第三方限制的内容。

### 299 元包含什么

我会交付一份诊断报告，通常包含：

- 故障现象摘要。
- 最可能的失败原因排序。
- 失败节点定位图或文字说明。
- 优先修复顺序。
- 需要你补充验证的最小测试步骤。
- 风险提醒，比如权限、数据、Token、成本、重复调用、死循环。
- 是否值得升级到修复服务的建议。

### 299 元不包含什么

为了把价格做低，299 元只做诊断，不包含：

- 直接登录你的账号帮你修。
- 保证一定修好所有问题。
- 大规模重构流程。
- 长期托管、代运营、模型成本优化全案。
- 处理收款、实名、KYC、钱包、付款、爬虫绕过、平台风控等敏感问题。

### 什么时候需要升级

如果诊断后发现问题比较明确，可以升级：

- 999 元：小范围修复建议或脚本级修复方案，适合单流程、单报错、单接口。
- 1999 元以上：复杂自动化链路、多个平台、多节点、多模型、多轮测试或需要完整交付文档。

升级前会先确认范围，不会默认加价。

### 交付流程

1. 你发脱敏材料。
2. 我先判断是否适合 299 诊断。
3. 适合后确认范围。
4. 输出诊断报告。
5. 如果需要修复，再单独报价，不强制升级。

### 可直接发给买家的第一句话

你先不用给我账号，也不用发密钥。把报错截图、失败节点、你期望的输出和实际输出发我，我先判断能不能按 299 元做一次 AI 自动化故障诊断。能做我会告诉你交付内容，不能做我也会直接说清楚，避免你白花钱。

## Internal Qualification Checklist

Accept the 299 diagnosis only when:

- The buyer can provide screenshots or text logs without secrets.
- The problem is a concrete failure, not a vague full build request.
- The expected output and actual output can be described.
- The diagnosis can be delivered as a report without account access.
- No KYC, payment, wallet, scraping bypass, spam, or platform evasion is involved.

Decline or re-scope when:

- The buyer asks for direct login before sharing any error evidence.
- The buyer sends off-platform links as the only context.
- The task requires private data or production credentials.
- The buyer wants guaranteed recovery without diagnostics.
- The request is actually full development disguised as a diagnosis.
