# Rescue Buyer Brief

Send this brief to a buyer who wants emergency help but has not provided enough safe information yet.

## Copyable Brief

```text
Please paste the following details here on the platform:

1. What should the AI automation or agent workflow do?
2. What is failing right now?
3. What tool or stack is involved? Claude, GPT, Gemini, Node.js, GitHub Actions, browser automation, API calls, or something else?
4. Please paste the exact redacted error log or upload a screenshot.
5. If available, share a public repository link or paste the relevant workflow/script snippet.
6. What do you need back: diagnosis report, fix plan, small script, CI snippet, or implementation help?

Please remove API keys, tokens, passwords, private customer data, and payment information before sharing.
```

## Use This When

- The buyer says the workflow is broken but gives no logs.
- The buyer sends an external link before a platform order exists.
- The buyer asks whether the issue can be fixed but scope is unclear.
- The buyer wants a custom offer and needs a clean scope first.

## Recommended Offer After Brief

Use the buyer's response to choose:

- USD 99: simple redacted log or screenshot diagnosis.
- USD 299: full diagnosis plus fix plan.
- USD 599: emergency rescue with a small scoped script or workflow snippet.

## Safety Rule

If the buyer cannot provide safe inputs inside the platform, do not proceed. Ask for redacted logs, screenshots, public links, or pasted snippets only.
