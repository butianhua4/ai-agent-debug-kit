## FAQ

### Can you log into my n8n / Make / Zapier account?

The default package is report-only and does not require passwords, API secrets, or account access. If implementation is needed later, scope and access must be agreed separately.

### Can you guarantee the workflow will be fixed?

I can diagnose likely causes and provide a safe repair plan. I cannot guarantee fixes for third-party outages, missing platform permissions, broken vendor APIs, or hidden private account settings.

### Can I send API keys or tokens?

No. Please remove secrets before sharing screenshots, logs, or exported workflow JSON.
