# Domestic Outreach Scripts

Use these short scripts for WeChat, Xianyu, Xiaohongshu, Zhihu, Juejin, Bilibili comments, private communities, and creator/operator groups.

Goal: create qualified inbound conversations for the automation rescue offer without asking for passwords, API keys, payment details, KYC, wallets, or private customer data.

## Core Offer

中文定位：

> 我帮你排查 n8n / Make / Zapier / webhook / API / JSON 映射 / AI 自动化流程失败问题。先诊断，不碰账号，不要密码，不要 API Key，交付一份可执行的失败原因、修复顺序和测试清单。

English positioning:

> I diagnose broken AI automations and agent workflows without needing passwords or API keys. Send the platform, failed step, error text, recent changes, expected output, and actual output. I return a clear failure map, fix order, and test checklist.

## 15-Second WeChat Reply

可以，我先不碰你的账号，也不需要密码或 API Key。  
你把这 6 个信息发我就行：

1. 用的平台：n8n / Make / Zapier / Pipedream / 自建脚本 / 其他
2. 失败的是哪一步
3. 完整错误文本
4. 最近改过什么
5. 你期望输出什么
6. 实际输出什么

如果有截图或 workflow 导出，请先删掉 API Key、Token、密码和客户隐私。我先判断能不能固定范围诊断，再给你报价。

## Short Public Post

接自动化流程故障诊断：n8n / Make / Zapier / webhook / API / JSON 映射 / AI 自动化成本异常。  

适合这些问题：

- webhook 收不到数据
- API 请求突然失败
- JSON 字段映射错乱
- CRM / 表格 / 邮件步骤缺字段
- 循环重试、重复发送
- AI 自动化成本突然变高
- 之前能跑，现在突然不稳定

我先做诊断，不要你的密码，不要 API Key。交付失败原因、风险等级、修复顺序和测试清单。  
入门诊断 299，标准救援报告 999，紧急业务救援 1999 起。

## Comment Hooks

Use these as short comments under posts discussing automation failures, AI workflow costs, n8n, Zapier, Make, or webhook issues.

1. 这个看起来像 webhook / 字段映射链路的问题，别先改一堆节点，先把失败步骤、错误文本、期望输出和实际输出对齐，通常能很快缩小范围。
2. 如果是 n8n / Make / Zapier 之前能跑、现在突然失败，优先查最近改动、输入字段变化、重试循环和鉴权过期，不建议直接重做整条流程。
3. AI 自动化成本突然飙升，常见原因是循环重试、重复触发、上下文变长或模型路由没兜底，先做一次失败/成本地图会更稳。
4. JSON 映射错乱不要急着换平台，先看上游 payload 有没有变字段名、数组层级、空值或类型。
5. 如果不方便给账号，也可以只发脱敏错误文本和流程截图，先做固定范围诊断。

## Price Ladder Replies

### 299 RMB Diagnosis

这个适合先做 299 入门诊断。交付一页报告：可能原因、失败步骤/字段、安全测试清单和下一步修复建议。默认不需要账号密码。

### 999 RMB Rescue Report

这个涉及完整流程，建议做 999 标准救援报告。交付流程失败地图、根因分析、字段/JSON 映射修复建议、重复发送/重试风险提示和 Before/After 测试清单。

### 1999+ RMB Urgent Rescue

如果这个流程正在影响线索、CRM、内容生产或业务运行，可以走 1999+ 加急救援。交付优先诊断、风险地图、修复顺序、备用路径、监控清单和团队交接报告。

## Safety Refusal

这个需求我暂时不能接，因为涉及账号敏感权限、支付/KYC/钱包/身份/税务/未脱敏客户数据。建议先走平台官方支持或内部有权限的人处理。我这边可以处理脱敏后的错误文本、失败步骤和流程逻辑诊断。

## Do Not Send

Avoid these claims:

- 保证修好
- 五小时一定恢复
- 不需要你提供任何信息
- 可以绕过平台限制
- 可以帮你登录任何账号
- 可以处理支付/KYC/钱包/身份证
- 已经服务过某某真实客户 unless that case is real and approved
