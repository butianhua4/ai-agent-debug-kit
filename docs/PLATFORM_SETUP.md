# Platform Setup Checklist

This checklist turns AI Agent Debug Kit into freelance listings without touching passwords, payout settings, private repositories, or paid subscriptions.

The operator can prepare copy and assets. The user must personally handle login, identity checks, payout setup, publishing, and any paid upgrades.

## Platform Priority

1. Fiverr: first choice for fixed service packages.
2. Upwork Project Catalog: passive listing while avoiding Connects spend.
3. Chinese freelance platforms: use localized service copy and domestic payment flow.
4. Bounty platforms: continue screening only for open, low-competition issues.

## Fiverr Setup

### Account Actions The User Must Do

- create or log into Fiverr
- switch to seller mode
- complete profile and identity checks if requested
- configure payout method only after reviewing the platform flow
- click final Publish

### Gig 1

Title:

`I will debug your AI agent logs and deliver a readable failure report`

Category:

Programming & Tech / AI Development or Software Development

Price:

- Basic: USD 49
- Delivery: 2 days
- Revisions: 1

Description:

```text
I will review your redacted AI agent logs and deliver a clear Markdown/JSON debug report.

Good fit for:
- AI agent tool-calling failures
- automation logs
- JSONL, JSON, or plain-text run logs
- permission errors
- retry loops
- cost spikes
- risky log content

You will receive:
- Markdown debug report
- JSON summary report
- top suspected failure causes
- risk flags
- next-step recommendations

No production credentials are required. Please remove API keys, tokens, passwords, customer data, and private repository names before sending logs.
```

Requirements:

```text
Please send:
1. Redacted JSONL, JSON, or plain-text logs.
2. The tool or framework name if known.
3. What you expected the agent to do.
4. What failed or looked suspicious.
5. Whether you need a report only or a follow-up fix quote.
```
