## Listing Copy

AI Agent Debug Kit is a local-first tool for inspecting AI agent logs.

Paste JSONL, JSON, or plain text and get event counts, tool-call breakdowns, error flags, cost estimates, repeated-pattern detection, and Markdown/JSON reports.

No backend. No account. No install required for the browser app.

## Buyer Use Cases

- inspect failed agent runs
- attach reports to PRs
- compare two agent runs
- gate CI on agent errors
- redact reports before sharing
- package a lightweight internal debugging tool
