# Custom Offer: Automation Failure Rescue

Use this when Fiverr blocks a new gig because the account already has the maximum number of active gigs, or when a buyer asks about a workflow failure through an existing gig.

## When To Use

Use this custom offer when the buyer mentions:

- n8n workflow failed
- Make scenario error
- Zapier zap skipped records
- Webhook not receiving data
- API request failed
- JSON mapping changed
- duplicate sends or retry loops
- AI workflow cost spike

Do not use this if the buyer asks for payout, KYC, tax, wallet, hacking, credential recovery, scraping private systems, or off-platform payment.

## Safe Qualification Reply

Thanks. I can help diagnose this as an automation failure rescue. Please send:

1. Platform name: n8n, Make, Zapier, Pipedream, custom Node.js, or other.
2. The failed step name.
3. The exact error text.
4. What changed recently.
5. A screenshot or exported workflow with secrets removed.

Please do not send passwords, API keys, OAuth tokens, payment data, or private customer records. I will first confirm the fixed scope before implementation work.
