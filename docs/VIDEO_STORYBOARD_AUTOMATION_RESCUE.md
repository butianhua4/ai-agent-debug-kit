# Video Storyboard: Automation Failure Rescue

This is a 35-45 second Fiverr gallery video plan for the n8n / Make / Zapier automation failure rescue offer.

## Goal

Show a buyer that the service is practical, safe, and report-driven. Do not overpromise full account repair without scope review.

## Scene 1 - Problem

Text:

Your automation still triggers, but the CRM step fails.

Visual:

Webhook -> JSON mapping -> CRM, with the CRM card marked as failed.

Voiceover:

When a form, webhook, or API payload changes, your workflow can keep running while silently sending bad data.

## Scene 2 - Diagnosis

Text:

Find the broken field path.

Visual:

Before: `email = {{$json["email"]}}`

After: `email = {{$json["lead"]["email"]}}`

Voiceover:

I inspect the failing step, error text, and redacted workflow data to identify the broken mapping or retry risk.

## Scene 3 - Delivery

Text:

You get a repair report and safe test plan.

Visual:

Checklist: root cause, risk level, corrected mapping, retry safety, next test.

Voiceover:

The delivery is a clear report you can test safely before production retries or customer messages are re-enabled.

## Scene 4 - Boundary

Text:

No passwords. No API secrets. Redacted data only.

Visual:

Lock icon next to "redacted logs / screenshots / workflow export".

Voiceover:

For diagnosis, please remove secrets and private customer data before sharing files.

## Scene 5 - CTA

Text:

Automation Failure Rescue - from $49

Visual:

Fiverr profile: `aibuildflow`

Voiceover:

Send the failed step and exact error text, and I will confirm the safest fixed-scope diagnosis.
