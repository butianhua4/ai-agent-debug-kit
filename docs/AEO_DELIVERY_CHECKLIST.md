# AEO Delivery Checklist

Use this checklist for the AEO / AI Search Readiness Audit.

## Intake

- [ ] Public URL received
- [ ] Target buyer received
- [ ] Target action received
- [ ] Keywords or competitors received, if available
- [ ] Package selected
- [ ] Payment/order path is inside approved platform
- [ ] No passwords, private analytics, customer data, API keys, or private repository access requested

## Page Review

- [ ] Page title is clear
- [ ] First screen explains who the offer is for
- [ ] First screen explains the problem solved
- [ ] First screen explains the output or result
- [ ] CTA is visible and specific
- [ ] Trust signals are visible
- [ ] Pricing or scope is discoverable
- [ ] FAQ or question-answer content exists
- [ ] Privacy/safety signals exist when relevant
- [ ] Public proof exists: demo, GitHub, screenshots, case study, sample report, or testimonials

## Answer Engine Checks

- [ ] Can an AI answer "what is this?"
- [ ] Can an AI answer "who is it for?"
- [ ] Can an AI answer "what problem does it solve?"
- [ ] Can an AI answer "what does the buyer get?"
- [ ] Can an AI answer "how much does it cost?"
- [ ] Can an AI answer "why trust it?"
- [ ] Can an AI answer "what should the buyer do next?"

## Rewrite Suggestions

- [ ] One-sentence offer
- [ ] Better page title
- [ ] Better meta description
- [ ] 3-5 FAQ questions
- [ ] Structured-data fields
- [ ] Trust-signal improvements
- [ ] CTA improvements

## Report Structure

- [ ] Page summary
- [ ] Current positioning
- [ ] AEO gaps
- [ ] Recommended rewrite
- [ ] FAQ draft
- [ ] Structured-data draft
- [ ] Next actions
- [ ] Scope boundary reminder

## Delivery Message

```text
Hi, the AEO readiness audit is complete.

I reviewed the public page you provided and focused on whether AI search / answer engines can clearly understand:

- what the page offers
- who it is for
- what problem it solves
- what proof or trust signals exist
- what action the buyer should take next

Attached is the report with the main gaps, rewrite suggestions, FAQ ideas, structured-data fields, and next actions.

I did not use private logins, customer data, paid SEO tools, or private repositories.
```

## Upgrade Offer

```text
If you want, the next step is a rewrite / implementation package:

- rewrite the headline, page intro, FAQ, and service description
- add structured-data copy
- prepare a stronger public proof section
- implement the copy if the page is static/public and the scope is approved

I can quote that separately after you review the audit.
```
