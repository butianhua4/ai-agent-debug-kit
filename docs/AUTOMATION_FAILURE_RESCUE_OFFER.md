# n8n / Make / Zapier Automation Failure Rescue

This is a fixed-scope service package for buyers whose no-code or low-code automation stopped working and needs a clear diagnosis instead of a vague rebuild quote.

## Buyer Problem

Common buyer messages:

- My n8n workflow suddenly fails after an API or webhook change.
- My Make scenario runs but sends wrong data to the next step.
- My Zapier automation is stuck, looping, or skipping records.
- My HTTP request / webhook / JSON mapping works in one test but fails in production.
- My AI automation costs more than expected or retries too often.

## Service Promise

I will review the workflow symptoms, logs, screenshots, exported workflow JSON when available, and error messages. I will return a practical repair report with the likely root cause, risk level, safe fix steps, and the next test to run.

This offer is for debugging and repair guidance. It does not require access to private accounts unless the buyer explicitly chooses a live implementation add-on.

## Buyer Inputs

Ask for these inputs before accepting the scope:

1. Platform: n8n, Make, Zapier, Pipedream, custom Node.js, or other.
2. What changed recently.
3. Error text or screenshot.
4. Which step fails.
5. Expected output.
6. Actual output.
7. Whether the workflow touches payments, personal data, or login credentials.
8. Exported workflow JSON if the buyer can safely share it.

Do not request passwords, API secrets, OAuth tokens, private customer data, payment data, or identity documents.
