# Chinese 299 Custom Offer Pack

Use this when a buyer has shared enough redacted material for a RMB 299 diagnosis, or when you need to create a Fiverr Custom Offer / domestic chat payment message for the entry-level AI automation diagnosis service.

The offer is for diagnosis and next-step guidance only. It does not include direct account login, production operation, code deployment, credential handling, KYC, tax, wallet, payment, or platform-bypass work.

## Offer Title

AI 自动化故障诊断报告（脱敏材料版）

## One-Line Offer

我会基于你提供的脱敏截图、报错和样例输入输出，整理一份 AI 自动化故障诊断报告，指出最可能的问题节点、原因、最小测试步骤和下一步修复建议。

## Fiverr Custom Offer Description

I will review the redacted workflow screenshots, error messages, and sample input/output you provide, then deliver a concise AI automation diagnosis report.

The report will include:

- likely failure point;
- likely root cause;
- evidence from the provided materials;
- safe minimal test steps;
- pass/fail signals;
- risk notes;
- whether the issue should stay as diagnosis, upgrade to a scoped repair plan, or be re-scoped.

This offer does not include logging into your accounts, handling passwords/API keys/tokens/cookies, editing production systems, payment/KYC/tax/wallet work, or platform-bypass work.

Delivery: 1 day.
